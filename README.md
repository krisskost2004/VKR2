# Сравнительный анализ метаэвристических алгоритмов оптимизации для настройки регуляторов

Данный проект реализован в рамках выпускной квалификационной работы бакалавра по направлению «Управление в технических системах». 
Цель работы - сравнение эффективности пяти современных метаэвристических алгоритмов при решении задач параметрической настройки регуляторов для технических систем с различной динамикой.

## Алгоритмы

В проекте реализованы и протестированы следующие алгоритмы:

| Алгоритм | Аббревиатура | Тип |
|----------|---------------|------|
| Метод роя частиц | PSO | Роевой |
| Алгоритм серого волка | GWO | Иерархический |
| Алгоритм китовой оптимизации | WOA | Биомиметический |
| Алгоритм ястребов Харриса | HHO | Кооперативный |
| Алгоритм слизевидных амёб | SMA | Биологически инспирированный |

Все алгоритмы реализованы с единым интерфейсом (`BaseOptimizer`) и поддерживают:
- задание границ поиска,
- настраиваемые размер популяции и число итераций,
- запись истории сходимости (с начальной оценки популяции),
- воспроизводимость через `seed`.

## Объекты управления

Исследование проведено на трёх моделях, охватывающих основные классы динамических систем:

1. **Линейная минимально-фазовая система** - двигатель постоянного тока с ПИД-регулятором.
   - Передаточная функция двигателя:  
   - Целевая функция: ITAE + штраф за перерегулирование + штраф за ошибку на «хвосте».

2. **Неустойчивая система** - перевёрнутый маятник на тележке.
   - Линеаризованная модель в пространстве состояний.
   - Закон управления: \( u = -Kx \).

3. **Нелинейная система с шумами и ограничениями** - два связанных резервуара.
   - Нелинейные потоки, квадратичная зависимость сопротивления от уровня.
   - Динамически изменяющиеся уставки.
   - Гауссов шум измерений (фиксируется через `seed` для воспроизводимости).
   - Целевая функция учитывает абсолютную ошибку, плавность управления, колебания и финальную ошибку.

## Установка и запуск
### Требования

- Python 3.8 или выше

### Установка зависимостей

- pip install -r requirements.txt

### Запуск эксперимента
- python experiment.py

После выполнения эксперимента все результаты автоматически сохраняются в папку results/.

### Построение графиков
После завершения эксперимента (или при наличии уже сохранённых результатов) можно построить графики:

- python visualization.py          # графики сходимости

- python plot_step_responses.py   # графики переходных процессов 

Все графики сохраняются в папку plots/.

## Структура результатов
После завершения экспериментов в директории results/ создаются следующие файлы:

- summary_results.csv – сводная таблица, содержащая для каждой комбинации (задача, алгоритм) все перечисленные выше метрики: Best_Fitness_Mean, Best_Fitness_Std, Best_Fitness_Median, Best_Fitness_Q25, Best_Fitness_Q75, Execution_Time_Mean, Execution_Time_Std, Feasible_Rate_%, Acceptable_Rate_%, Median_J@50%, Median_J@75%, Median_J@100%, а также столбцы для инженерных метрик (например, overshoot_mean, overshoot_std, overshoot_median, overshoot_q25, overshoot_q75 и т.д.).

- results.json – полные детальные результаты всех запусков (включая векторы решений, значения метрик для каждого запуска, истории времени).

- convergence.json – списки историй сходимости (по одному списку на запуск) для каждого алгоритма и задачи.

- convergence_time.json – истории накопленного времени по итерациям (используется для анализа временной сложности).

- params.json – параметры эксперимента (num_runs, max_iter, pop_size, временная метка).

Папка plots/
Содержит все сгенерированные графики:

- convergence_{задача}.png – графики сходимости для каждой задачи по 20 запускам.
- step_response_{задача}.png - графики переходных процессов для каждой задачи.
